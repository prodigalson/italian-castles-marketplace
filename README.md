# Italian Castles Marketplace

A Vite static marketplace MVP for Italian castles for sale. The current inventory is a compliant manual/link-only fixture: source links, source status, last-checked times, provenance, and inquiry actions are preserved, while unavailable or permission-gated sources are represented transparently instead of scraped.

## Local Setup

Requirements:

- Node.js 20 or newer.
- npm.

Install dependencies:

```bash
npm install
```

Run the local app:

```bash
npm run dev
```

Build the deployable static site:

```bash
npm run build
```

Preview the built site locally:

```bash
npm run preview
```

## Data Refresh

The castle inventory is generated by `scripts/refresh-castle-inventory.mjs`.

```bash
npm run inventory:refresh
```

The refresh writes:

- `data/castle-listings.json` for canonical marketplace listings.
- `data/castle-source-status.json` for source-level compliance and availability status.

The current adapter is intentionally manual and link-only. It does not scrape public listing pages. Before adding an automated adapter, update `docs/castle-data-foundation.md` with dated robots and terms evidence, confirm the exact paths/endpoints are permitted, and preserve attribution, license basis, last-checked time, and inquiry route in every emitted record.

## Deployment

This repo is configured for Vercel via `vercel.json`.

Deployment build command:

```bash
npm run build
```

Static output directory:

```text
dist
```

The build runs `vite build` and emits the static app to `dist`.

## Launch Checks

Launch-readiness evidence is tracked in `docs/launch-readiness.md`. Before launch, rerun:

```bash
npm run inventory:refresh
npm run build
```

Then verify the built app in desktop and mobile widths, including:

- Cover page, enter flow, listing navigation, gallery thumbs, filters, sharing fallback, and source links.
- Source attribution, stale/removed labels, last-checked time, provenance text, and inquiry actions.
- SEO metadata, canonical URL, Open Graph/Twitter preview tags, `robots.txt`, and structured data.
- Keyboard navigation, focus states, form labels, responsive layout, and reduced-motion behavior.
